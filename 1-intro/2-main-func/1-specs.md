### 1.2.1. 关键特性规格

<br>

| 关键特性规格 | 备注 | 
| :---: | :---: | 
| 协作机器人数量 | 最多 4 |
| 通信方式 | 通用以太网 (UDP) |
| 通信速度 | 100 Mbps |
| 支持的主设备数量 | 1 |
| 支持的从设备数量 | 每个主设备最多 3 个从设备 |
| 驱动轴 | 支持驱动轴协作 |
| HiNet I/O | 每个机器人 12 字节 (输入/输出信号) |
| 无夹具协作 | 支持机器人与定位器之间的无夹具协作 |
